# 权限管理升级说明

空白的 HTTP 路径不再授予任何路由访问权限。仅通过标识检查的按钮权限仍可保留空路径；需要访问后台根路径时填写 `/`，需要所有后台路由时显式填写 `*`。空行会被忽略，HTTP 方法留空仍表示不限方法。

同一路由上的多个 `admin.permission:*` 条件现在必须全部满足，包括路由组及控制器上的条件。`free` 不会跳过其他权限条件。独立使用带参数的权限中间件也会执行检查。

新安装的 `auth.management` 权限包含用户、角色、权限、菜单和操作日志的资源路径。已有安装不会自动覆盖数据库中的自定义权限配置；如需使用完整的管理权限，可编辑该权限的 HTTP 路径为：

```text
/auth/users
/auth/users/*
/auth/roles
/auth/roles/*
/auth/permissions
/auth/permissions/*
/auth/menu
/auth/menu/*
/auth/logs
/auth/logs/*
```

以上路径相对于后台前缀，HTTP 方法留空。分配该权限会允许管理用户及其角色、权限，应仅授予相应的管理人员。

删除权限会清理角色授权和用户直属授权，删除角色会清理用户、权限和菜单关联。本次修改不会回溯清理数据库中此前已经存在的孤立关联记录。
